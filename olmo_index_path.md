## 1. Why does `olmo_index_path` exist?

The Allen Institute for AI (AI2) OLMo (Open Language Model) pretraining framework stores pre-tokenized corpora as collections of raw contiguous 16-bit or 32-bit NumPy arrays (`.npy` files) memory-mapped to disk.

```text
build_olmo_npy_index.py ──> Generates olmo_index.json (Chunk boundaries, file offsets)
                                   │
                                   ▼
                            [olmo_index_path]
                                   │
                                   ▼
      MaxText OLMo Data Loader maps exact token offsets across hundreds of npy files
```

`olmo_index_path` points to the precomputed JSON index file generated by MaxText's `tools/data_generation/build_olmo_npy_index.py` tool.

---

## 2. Mechanics

In `src/maxtext/input_pipeline/_olmo_data_processing.py`:
1. MaxText reads `olmo_index_path` to load file metadata, document lengths, and sample offsets.
2. It memory-maps the referenced `.npy` files and slices exact token sequences without decoding or string parsing overhead.
3. Reuses `grain_worker_count` and `grain_per_worker_buffer_size` for worker pool management.

---

## 3. Options & Default

| Parameter | Type | Default | Options |
| :--- | :--- | :--- | :--- |
| `olmo_index_path` | `str` | `''` | Local path or `gs://` URI to index JSON file |

---

## 4. Interactions with Related Parameters

- **`dataset_type`**: Must be `'olmo_grain'`.
- **`olmo_path_remap_from` & `olmo_path_remap_to`**: Path translation rules for cloud storage mounts.

---

## 5. Practical Scenarios & Failure Modes

| Scenario | Symptom / Failure | Fix |
| :--- | :--- | :--- |
| **Training on OLMo Dolma dataset** | Missing index file error | Run `build_olmo_npy_index.py` first and point `olmo_index_path` to generated JSON. |

---

### One-line intuition

> `olmo_index_path` provides the path to the JSON index file mapping sample offsets across pre-tokenized OLMo NumPy dataset arrays.
