### YaRN RoPE parameters

YaRN ("Yet another RoPE extensioN") is a technique for extending a model's effective context length beyond what it was originally trained on, by non-uniformly rescaling rotary frequencies. Only relevant when `rope_type="yarn"`.

| Param                                | Purpose                                                                                                                                                                                                                                     | Options / meaning                  | Deep Dive                              |
| ------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------- | -------------------------------------- |
| `max_position_embeddings`            | The extended (target) maximum context length YaRN scales up to.                                                                                                                                                                             | Integer, default `163_840`.        | [[max_position_embeddings]]            |
| `original_max_position_embeddings`   | The context length the model was originally trained/pretrained at, before YaRN extension.                                                                                                                                                   | Integer, default `4096`.           | [[original_max_position_embeddings]]   |
| `rope_factor`                        | The scaling factor between original and extended context (roughly `max_position_embeddings / original_max_position_embeddings`).                                                                                                            | Integer, default `40`.             | [[rope_factor]]                        |
| `beta_fast`                          | YaRN's "fast" correction-range boundary parameter — controls where high-frequency (short-wavelength) rotary dimensions transition to being scaled.                                                                                         | Integer, default `32`.             | [[beta_fast]]                          |
| `beta_slow`                          | YaRN's "slow" correction-range boundary parameter — the equivalent boundary for low-frequency (long-wavelength) dimensions.                                                                                                                 | Integer, default `1`.              | [[beta_slow]]                          |
| `mscale`                             | Magnitude scaling factor applied alongside the frequency rescaling, to help stabilize attention logit magnitudes at extended context lengths.                                                                                              | Float, default `1.0`.              | [[mscale]]                             |
| `rope_interleave`                    | Whether sin/cos rotary components are interleaved (vs. concatenated) in the tensor layout.                                                                                                                                                  | `true`/`false`, default `true`.    | [[rope_interleave]]                    |
| `rope_truncate`                      | Floors the lower bound and ceils the upper bound of YaRN's correction range.                                                                                                                                                                | `true`/`false`, default `true`.    | [[rope_truncate]]                      |
| `rope_attention_scaling`             | Whether to additionally scale the rotary embedding's output magnitude.                                                                                                                                                                      | `true`/`false`, default `false`.   | [[rope_attention_scaling]]             |
| `rope_pairwise`                      | Keeps the rank-5 pair tensor intact — shape `[batch_size, sequence_length, num_heads, half_dim, 2]`, where `half_dim` is the number of 2D rotation planes and the last axis of size 2 holds `[real, imag]` coordinates — returning interleaved RoPE in that representation rather than a flattened one. | `true`/`false`, default `false`.   | [[rope_pairwise]]                      |

## Notes to self

- RoPE's config surface has a lot of Gemma4- and DeepSeek/YaRN-specific escape hatches layered onto a fairly simple core idea (rotate Q/K by position-dependent angles). The `rope_type` switch is the fork point — `"default"` and `"llama3.1"` share most of the plain params, while `"yarn"` pulls in the whole separate YaRN block.
- `eval_interval=-1` and `target_eval_loss=0.` both defaulting to "off" is a pattern worth remembering: MaxText's `base.yml` defaults tend toward the minimal/fast-iterating config, with most of the monitoring/eval/production-hardening features opt-in — makes sense for a research-first framework, but means a lot of these need explicit enabling for a real production pretraining run.
- Goodput vs. plain uptime is a distinction worth internalizing if you haven't worked with it before: a job can be "up" 100% of the time while actually making training progress only 80% of the time (checkpoint stalls, data-loading hiccups, preemption recovery) — Goodput is what's actually tracking the number you care about.
